NEON SOCIAL — полная версия
============================

Что есть в этом сайте:
- Регистрация и вход по логину/паролю
- Загрузка аватара
- Запросы в друзья: отправка, принятие, отклонение
- Уведомления: когда друг заходит на сайт, когда вам пришёл запрос,
  когда кто-то лайкнул/прокомментировал ваш пост, когда пришло сообщение
- Личные сообщения (только между друзьями)
- Посты, лайки, комментарии
- Тёмная неоновая тема, адаптация под телефон


КАК ЗАПУСТИТЬ НА СВОЁМ КОМПЬЮТЕРЕ (VS Code / терминал)
--------------------------------------------------------
1) Установить зависимости:

   python -m pip install -r requirements.txt

2) Запустить сайт:

   python app.py

3) Открыть в браузере:

   http://127.0.0.1:5000

При первом запуске автоматически создастся файл базы данных
neon_social.db — ничего дополнительно настраивать не нужно.


КАК ПРОВЕРИТЬ ФУНКЦИИ
--------------------------------------------------------
1. Зарегистрируйте аккаунт A, затем аккаунт B (выйдите и зарегистрируйте
   второй, либо откройте два разных браузера / окна инкогнито).
2. Войдите как A, откройте профиль B (можно перейти на
   http://127.0.0.1:5000/profile/ИМЯ_B) и нажмите «Добавить в друзья».
3. У B появится уведомление и запись в разделе «Запросы».
4. B заходит в «Запросы» → «Принять».
5. Теперь A и B — друзья: доступны личные сообщения, лайки и комментарии
   видны друг другу в ленте.
6. Когда один из друзей заходит на сайт (логинится), второй получает
   уведомление об этом в разделе «Уведомления».


ХОСТИНГ — ЧТОБЫ САЙТ ОТКРЫВАЛСЯ У ДРУЗЕЙ ЧЕРЕЗ ИНТЕРНЕТ
--------------------------------------------------------
Сейчас сайт работает только на вашем компьютере (127.0.0.1 — это "localhost",
его видите только вы). Чтобы друзья могли зайти по ссылке из любого места,
нужно разместить проект на хостинге. Проще всего — бесплатные варианты:

ВАРИАНТ 1: Render.com (рекомендуется, бесплатно, просто)
  1. Зарегистрируйтесь на https://render.com
  2. Загрузите этот проект к себе на GitHub (создайте репозиторий и
     закиньте туда все файлы папки).
  3. На Render нажмите "New +" → "Web Service", подключите ваш GitHub
     репозиторий.
  4. В настройках укажите:
       Build Command:   pip install -r requirements.txt
       Start Command:   gunicorn app:app
  5. Добавьте в requirements.txt строку "gunicorn" (без кавычек).
  6. Нажмите Deploy — через пару минут Render даст вам постоянную
     ссылку вида https://ваш-сайт.onrender.com — её и присылайте друзьям.

ВАРИАНТ 2: PythonAnywhere (тоже бесплатно)
  1. Зарегистрируйтесь на https://www.pythonanywhere.com
  2. Загрузите файлы проекта через раздел "Files".
  3. В разделе "Web" создайте новое Flask-приложение, укажите путь к app.py.
  4. Нажмите "Reload" — сайт станет доступен по адресу
     https://ваш_логин.pythonanywhere.com

ВАЖНО для любого хостинга:
- В файле app.py уберите/замените debug=True на debug=False перед
  публикацией (в целях безопасности), это одна строка в самом низу файла:
      app.run(debug=True, host="0.0.0.0", port=5000)
  замените на:
      app.run(debug=False, host="0.0.0.0", port=5000)
- Смените SECRET_KEY в app.py на свою собственную случайную строку.

Если при деплое или запуске появится ошибка — пришлите мне текст ошибки
(или скриншот терминала), и я помогу её исправить.
